# Harness Engineering — AIエージェント開発環境の構築と社内展開

AIエージェント向け開発環境(ハーネス)を、個人の設定から社内チームの標準へと構築・配布・定着させてきた記録をまとめたポートフォリオ用の1ページサイト。

フック・コンテキストルーティング・自己改善ループといった構築物の仕組みと、導入後の運用実績・未解決の課題までを、スクロールで通して見せる構成になっている。

## ライブデモ

https://j-paku.github.io/ai-harness/

## 主な特徴

- **スナップスクロール**
  ホイール1回でパネル1枚分進む。画面高を超える長いパネルは`is-tall`判定でスナップ対象から自動的に外れ、下方向に進めなくなる詰まりを防ぐ

- **2テーマ切替**
  ライト(Alucard)・ダーク(Dracula)を⚙メニューからワンクリックで切替。選択は`localStorage`に保存され、次回訪問時も復元される

- **インラインSVGダイアグラム**
  実行フロー・フック構成・コンテキストルーティングなど6種の図解をCSSテーマトークンに連動させ、配色はテーマ切替に追従する。パネル高に応じた高さキャップと、モバイル幅では横スクロール表示を備える

- **日韓言語切替**
  ⚙メニューから日本語(既定)・韓国語を切替。`data-i18n`属性で対応づけた255キーの辞書と`localStorage`で、テキスト・aria属性・ナビラベルまで一括で切り替える

## セクション構成

サイトは17パネル(`s0`〜`s16`)で構成され、次の流れで進む。

1. **Intro / 定義** — イントロと統計チップ、ハーネスエンジニアリングの位置づけ(ループ・コンテキスト・プロンプトエンジニアリングとの包含関係)
2. **実行フロー〜運用画面(構築)** — 準備・生成・評価の実行フロー、フック25個によるガードレール、遮断の実例、文書ルーティング、eval36ケースによる回帰検証、instinctによる自己改善ループ、複数セッション監視画面
3. **配布・定着支援(普及)** — インストール式配布パッケージと、マンツーマン支援・定例共有・勉強会による定着施策
4. **運用実績・生産性(効果)** — マルチエージェント運用の実績値と、導入前後のコミット数・追加行数の変化
5. **課題** — 効果の個人集中、量では測れない成果という2つの未解決点
6. **今後** — 生成から検証へ関心が移る中での次のアクション
7. **まとめ・クローズ** — 構築から配布・課題・今後までの総括

## サイトが扱う主な数値

導入前後2か月分の実測をチップ・棒グラフで提示している。

- チーム月間コミット **2.8倍**(60件 → 169件)
- コード追加行数 **約4倍**(15,811行 → 63,307行)
- AIチーム自動実行 **105件**(修正94 / レビュー11)、無介入完了率 **87.6%**
- 行動を強制するフック **25個**、ハーネス自体を検証するeval **36ケース**

## 技術構成

vanilla HTML/CSS/JSのみで構築されており、依存パッケージもビルド工程も持たない。

| ファイル | 役割 |
|---|---|
| `index.html` | 全17セクションのマークアップと、6種のインラインSVGダイアグラムを含む本体 |
| `style.css` | テーマトークン(`:root`のCSS変数)・レイアウト・スナップスクロール・アニメーションの定義 |
| `script.js` | テーマ/言語切替、パネル高さ判定によるスナップ制御、出現アニメーション、数値カウントアップ、棒グラフ伸長、進捗表示の制御 |
| `i18n.js` | 韓国語辞書(`data-i18n`キーに対応する255エントリ) |

## ローカルで見る

サーバーは不要。`index.html`をブラウザで直接開けばそのまま表示される。

外部依存もビルドツールも使っていないため、リポジトリを取得してファイルを開くだけで、ライブデモと同じ表示を確認できる。
